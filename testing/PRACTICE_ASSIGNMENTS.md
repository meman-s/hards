# Практические задания по тестированию

## Как использовать

1. Откройте файл `test_practice.py`
2. Найдите задание по нужной теме
3. Напишите тесты вместо TODO комментариев
4. Запустите тесты: `pytest test_practice.py -v`

## Структура заданий

### Задание 1: Pytest Fixtures

**Цель:** Научиться создавать и использовать фикстуры

**Задачи:**
1. Создайте фикстуру `bank_account` для `BankAccount` с начальным балансом 100.0
2. Создайте фикстуру `user_repo` с `scope="module"` для `UserRepository`
3. Создайте фикстуру с `autouse=True`, которая выводит "Starting test"

**Пример:**
```python
@pytest.fixture
def bank_account():
    return BankAccount(initial_balance=100.0)

def test_deposit(bank_account):
    bank_account.deposit(50.0)
    assert bank_account.balance == 150.0
```

### Задание 3: Параметризованные тесты

**Цель:** Использовать `@pytest.mark.parametrize` для тестирования с разными данными

**Задачи:**
1. Параметризованный тест для `Calculator.add`:
   - (2, 3, 5)
   - (0, 0, 0)
   - (-1, 1, 0)
   - (10.5, 2.5, 13.0)

2. Параметризованный тест для `Calculator.multiply`

3. Параметризованный тест для `Calculator.divide`, включая проверку деления на ноль

**Пример:**
```python
@pytest.mark.parametrize("a,b,expected", [
    (2, 3, 5),
    (0, 0, 0),
])
def test_add(a, b, expected):
    assert Calculator.add(a, b) == expected
```

### Задание 5: Тесты с моками

**Цель:** Использовать мокирование для изоляции тестов

**Задачи:**
1. Создайте мок для `smtp_client` используя `unittest.mock.Mock`
2. Напишите тест `send_email` с проверкой вызова `smtp_client.send`
3. Напишите тест `send_welcome_email`
4. Напишите тест для проверки `ValueError` при невалидном email

**Пример:**
```python
from unittest.mock import Mock

def test_send_email():
    mock_smtp = Mock()
    service = EmailService(smtp_client=mock_smtp)
    
    service.send_email("test@example.com", "Subject", "Body")
    
    mock_smtp.send.assert_called_once_with("test@example.com", "Subject", "Body")
```
