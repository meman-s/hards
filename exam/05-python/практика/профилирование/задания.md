## Задание 1: Неэффективный поиск в списке

### Описание
Дан код приложения, которое обрабатывает список пользователей и ищет их по email. Приложение работает медленно при большом количестве пользователей.

### Исходный код
```python
class UserService:
    def __init__(self):
        self.users = []
    
    def add_user(self, name, email):
        self.users.append({"name": name, "email": email})
    
    def find_user_by_email(self, email):
        for user in self.users:
            if user["email"] == email:
                return user
        return None
    
    def get_user_statistics(self):
        stats = {}
        for user in self.users:
            domain = user["email"].split("@")[1]
            if domain not in stats:
                stats[domain] = 0
            stats[domain] += 1
        return stats

# Тестовый сценарий
service = UserService()
for i in range(10000):
    service.add_user(f"User {i}", f"user{i}@example.com")

# Множественные поиски
for i in range(1000):
    service.find_user_by_email(f"user{i}@example.com")
```

## Задание 3: Неэффективная работа со строками

### Описание

### Исходный код
```python
def process_text(text):
    words = []
    current_word = ""
    
    for char in text:
        # Проверяем, является ли символ буквой или цифрой (часть слова)
        if char.isalnum():
            current_word += char
        else:
            if current_word:
                words.append(current_word)
                current_word = ""
    
    if current_word:
        words.append(current_word)
    
    stats = {}
    for word in words:
        word_lower = word.lower()
        if word_lower not in stats:
            stats[word_lower] = 0
        stats[word_lower] += 1
    
    return stats

# Тестовый сценарий
large_text = "word " * 100000
result = process_text(large_text)
```

### Исходный код
```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```

## Задание 6: Неэффективная сортировка и фильтрация

### Описание
Приложение фильтрует и сортирует большой список товаров. При большом количестве товаров приложение работает медленно.

### Исходный код
```python
class ProductService:
    def __init__(self):
        self.products = []
    
    def add_product(self, name, price, category):
        self.products.append({
            "name": name,
            "price": price,
            "category": category
        })
    
    def get_expensive_products(self, min_price):
        expensive = []
        for product in self.products:
            if product["price"] >= min_price:
                expensive.append(product)
        
        # Пузырьковая сортировка
        n = len(expensive)
        for i in range(n):
            for j in range(0, n - i - 1):
                if expensive[j]["price"] < expensive[j + 1]["price"]:
                    expensive[j], expensive[j + 1] = expensive[j + 1], expensive[j]
        
        return expensive

# Тестовый сценарий
service = ProductService()
for i in range(50000):
    service.add_product(f"Product {i}", i * 10, f"Category {i % 10}")

result = service.get_expensive_products(100000)
```

```python
def reverse_list(items):
    result = []
    for item in items:
        result.insert(0, item)  # O(n) операция!

def get_last_n_items(items, n):
    result = []
```

## Задание 9: Неэффективная работа со словарями

### Описание
Код использует множественные проверки `if key in dict` перед обращением к словарю. Это приводит к двойному обращению к словарю для каждой операции.

### Исходный код
```python
def count_items(items):
    stats = {}
    for item in items:
        if item not in stats:  # Первое обращение
            stats[item] = 0
        stats[item] = stats[item] + 1  # Второе и третье обращение
    return stats

def merge_dicts(dict1, dict2):
    result = {}
    for key in dict1:
        if key not in result:
            result[key] = 0
        result[key] = dict1[key]
    for key in dict2:
        if key not in result:
            result[key] = 0
        result[key] = result[key] + dict2[key]
    return result

# Тестовый сценарий
items = [i % 100 for i in range(100000)]
stats = count_items(items)

dict1 = {i: i * 2 for i in range(1000)}
dict2 = {i: i * 3 for i in range(500, 1500)}

```

## Задание 10: Неэффективное использование генераторов

### Описание
Код выполняет множественные проходы по данным: сначала создает список, затем фильтрует, затем сортирует. Также функция статистики делает несколько проходов по данным для вычисления разных метрик.

### Исходный код
```python
def process_data(data):
    squared = [x ** 2 for x in data]  # Первый проход
    filtered = [x for x in squared if x > 100]  # Второй проход
    sorted_data = sorted(filtered)  # Третий проход (сортировка)
    return sorted_data

def get_statistics(data):
    total = sum(data)  # Первый проход
    count = len(data)  # Второй проход (технически O(1), но отдельная операция)
    average = total / count if count > 0 else 0
    
    max_val = max(data)  # Третий проход
    min_val = min(data)  # Четвертый проход
    
    return {
        "total": total,
        "count": count,
        "average": average,
        "max": max_val,
        "min": min_val
    }

# Тестовый сценарий
large_data = list(range(100000))
processed = process_data(large_data)
stats = get_statistics(large_data)
```
