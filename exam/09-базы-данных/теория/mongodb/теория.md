# MongoDB: Теория для экзамена

## 1. Запросы

### Базовые операции

`find` возвращает курсор (результат можно дальше сортировать/ограничивать), `find_one` возвращает один документ или `None`.

```python
collection.find({})
collection.find({"status": "active"})
collection.find_one({"name": "Иван"})
collection.find({}).sort("created_at", -1).limit(10)
```

### Операторы сравнения

Операторы сравнения применяются к полю, и задаются объектом вида `{"поле": {"$op": value}}`.

- `$gt` - больше
- `$gte` - больше или равно
- `$lt` - меньше
- `$lte` - меньше или равно
- `$ne` - не равно
- `$in` - входит в список значений
- `$nin` - не входит в список значений

```python
collection.find({"age": {"$gte": 18, "$lte": 65}})
collection.find({"status": {"$in": ["active", "pending"]}})
```

### Логические операторы

Логические операторы нужны, когда условия нельзя выразить просто набором полей.

- `$and` - логическое И
- `$or` - логическое ИЛИ
- `$not` - логическое НЕ

Важно: фильтр вида `{"status": "active", "age": {"$gte": 18}}` уже означает логическое И, поэтому `$and` часто не нужен.

```python
collection.find({
    "$and": [
        {"age": {"$gte": 18}},
        {"status": "active"}
    ]
})

collection.find({
    "$or": [
        {"role": "admin"},
        {"role": "moderator"}
    ]
})
```

### Операторы для массивов

- `$all` - массив содержит все указанные элементы
- `$elemMatch` - хотя бы один элемент массива подходит под условие
- `$size` - точный размер массива

```python
collection.find({"tags": {"$all": ["python", "mongodb"]}})
collection.find({"scores": {"$elemMatch": {"$gte": 80}}})
collection.find({"items": {"$size": 3}})
```

### Update операции

`update_one/update_many` принимают:

- фильтр (какие документы обновлять)
- документ обновления (что именно изменить)

Документ обновления почти всегда содержит операторы (`$set`, `$inc`, `$push`, …). Если передать обычный объект без операторов, MongoDB заменит документ целиком.

Частые операторы обновления:

- `$set` - установить значение поля
- `$unset` - удалить поле
- `$inc` - увеличить число
- `$push` - добавить элемент в массив
- `$pull` - удалить элементы из массива
- `$addToSet` - добавить элемент в массив без дублей

```python
collection.update_one(
    {"_id": ObjectId("...")},
    {"$set": {"status": "active"}}
)

collection.update_many(
    {"status": "pending"},
    {"$set": {"status": "active"}}
)
```

### Delete операции

`delete_one` удалит один документ, `delete_many` удалит все документы, подходящие под фильтр.

```python
collection.delete_one({"_id": ObjectId("...")})
collection.delete_many({"status": "deleted"})
```

## 2. Агрегации

Агрегация - это pipeline (конвейер) стадий. Документы проходят стадии слева направо: каждая стадия получает входные документы и возвращает выходные.

Типичный порядок: `$match` (срезать лишнее) → преобразования → `$group` (сводная статистика) → `$sort`/`$limit`.

### Основные стадии

#### $match - фильтрация

Оставляет только документы, которые подходят под условие. Чем раньше стоит `$match`, тем меньше данных будет обрабатываться дальше.

```python
pipeline = [
    {"$match": {"status": "active", "age": {"$gte": 18}}}
]
```

#### $group - группировка

`$group` “схлопывает” много документов в меньшее число документов по ключу группировки.

- `"_id"` внутри `$group` - это ключ группировки (аналог `GROUP BY` в SQL)
  - `"_id": "$status"` означает “сгруппировать по полю status”
  - `"_id": None` означает “все документы в одну группу”
Поле `"_id"` в результате `$group` можно переименовать на следующей стадии через `$project` (например, вынести в `groupKey` и отключить `_id`).

- поля вроде `avg_total`, `count` - это значения, вычисленные по документам внутри каждой группы

Пример базовой группировки:

```python
pipeline = [
    {
        "$group": {
            "_id": "$category",
            "total": {"$sum": "$price"},
            "count": {"$sum": 1},
            "avg_price": {"$avg": "$price"},
            "max_price": {"$max": "$price"},
            "min_price": {"$min": "$price"}
        }
    }
]
```

Пример, который прямо объясняет кусок из `ответы.md`:

```python
pipeline = [
    {
        "$group": {
            "_id": "$status",
            "avg_total": {"$avg": "$total"}
        }
    }
]
```

Как это читается:

- `"_id": "$status"` - сгруппировать заказы по значению `status`
- `"avg_total": {"$avg": "$total"}` - внутри каждой группы посчитать среднее по полю `total`

То есть на выходе будут документы примерно вида:

- `{ "_id": "completed", "avg_total": 350.5 }`
- `{ "_id": "pending", "avg_total": 120.0 }`

#### $project - выбор и преобразование полей

`$project` формирует форму выходного документа: какие поля оставить и какие вычислить.

```python
pipeline = [
    {
        "$project": {
            "name": 1,
            "age": 1,
            "_id": 0
        }
    }
]
```

#### $sort - сортировка

Сортирует поток документов. `1` - по возрастанию, `-1` - по убыванию.

```python
pipeline = [
    {"$sort": {"created_at": -1}}
]
```

#### $limit и $skip - пагинация

`$skip` пропускает N документов, `$limit` ограничивает количество.

```python
pipeline = [
    {"$skip": 10},
    {"$limit": 20}
]
```

#### $unwind - развертывание массива

Если поле - массив, `$unwind` превращает один документ с массивом в несколько документов: по одному на элемент массива.

```python
pipeline = [
    {"$unwind": "$items"}
]
```

#### $lookup - объединение коллекций

`$lookup` делает join: для каждого документа ищет связанные документы в другой коллекции и складывает найденное в массив `as`.

```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user_info"
        }
    }
]
```

Часто после `$lookup` добавляют `$unwind`, если ожидается максимум один связанный документ, чтобы работать с объектом, а не с массивом.

### Агрегатные функции (аккумуляторы) в `$group`

Самые нужные:

- `$sum` - сумма или счетчик, если суммировать `1`
- `$avg` - среднее
- `$min` / `$max` - минимум / максимум
- `$first` / `$last` - первое / последнее значение в группе (обычно вместе с предварительным `$sort`)
- `$push` - собрать значения в массив (с дубликатами)
- `$addToSet` - собрать значения в массив (без дубликатов)

Пример “посчитать и собрать”:

```python
pipeline = [
    {
        "$group": {
            "_id": "$user_id",
            "orders_count": {"$sum": 1},
            "totals": {"$push": "$total"},
            "unique_statuses": {"$addToSet": "$status"}
        }
    }
]
```

### Частые выражения (expression operators)

Это “функции”, которые вычисляют значения внутри стадий:

- `$multiply` - перемножение
- `$add`, `$subtract`, `$divide`
- `$concat` - склеить строки
- `$year`, `$month`, `$dayOfMonth` - извлечь часть даты

Пример выручки как `quantity * price`:

```python
pipeline = [
    {"$unwind": "$items"},
    {
        "$group": {
            "_id": None,
            "revenue": {"$sum": {"$multiply": ["$items.quantity", "$items.price"]}}
        }
    }
]
```

### Пример: Статистика по категориям

```python
pipeline = [
    {"$match": {"status": "active"}},
    {
        "$group": {
            "_id": "$category",
            "total_revenue": {"$sum": "$price"},
            "order_count": {"$sum": 1},
            "avg_price": {"$avg": "$price"}
        }
    },
    {"$sort": {"total_revenue": -1}},
    {"$limit": 10}
]
result = list(collection.aggregate(pipeline))
```

## 3. Join ($lookup)

`$lookup` позволяет объединять коллекции. Главное помнить: результат всегда попадает в массив `as`, даже если совпадение одно.

### Базовый $lookup

```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user"
        }
    }
]
```

### $lookup с $unwind

Если ожидается один пользователь на заказ, удобно превратить массив `user` в объект.

```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user"
        }
    },
    {
        "$unwind": {
            "path": "$user",
            "preserveNullAndEmptyArrays": True
        }
    }
]
```

### Пример: Заказы с пользователем и товарами

Идея: развернуть `items`, подтащить товар через `$lookup`, затем собрать обратно через `$group` и `$push`.

```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user"
        }
    },
    {"$unwind": "$user"},
    {"$unwind": "$items"},
    {
        "$lookup": {
            "from": "products",
            "localField": "items.product_id",
            "foreignField": "_id",
            "as": "product"
        }
    },
    {"$unwind": "$product"},
    {
        "$group": {
            "_id": "$_id",
            "user_name": {"$first": "$user.name"},
            "total": {"$first": "$total"},
            "items": {"$push": {
                "product_name": "$product.name",
                "quantity": "$items.quantity",
                "price": "$product.price"
            }}
        }
    }
]
```

## 4. Индексы

Индекс ускоряет чтение (поиск/сортировку), но замедляет запись и занимает место. Индекс имеет смысл, если запросы повторяются и выборка достаточно селективная.

### Одиночный индекс

```python
collection.create_index("email")
collection.create_index([("created_at", -1)])
```

### Compound индекс (составной)

Порядок полей важен. Индекс `(a, b)` хорошо работает для запросов по `a` и по `a+b`, но не обязан помогать запросам только по `b`.

```python
collection.create_index([("user_id", 1), ("created_at", -1)])
```

Правило ESR (Equality, Sort, Range): сначала поля равенства, потом сортировка, потом диапазоны.

Пример запроса и подходящего индекса:

```python
collection.create_index([("status", 1), ("created_at", -1), ("price", 1)])
```

### Partial индекс

Partial индекс строится только по части документов, которые удовлетворяют условию. Это экономит место и ускоряет запросы, если условие совпадает с фильтром.

```python
collection.create_index(
    [("email", 1)],
    partialFilterExpression={"status": "active"}
)
```

### Text индекс

Text индекс нужен для `$text` поиска.

```python
collection.create_index([
    ("title", "text"),
    ("description", "text")
])

collection.find({"$text": {"$search": "mongodb python"}})
```

### Проверка использования индекса

`explain()` показывает план выполнения. Если MongoDB использует индекс, часто увидишь стадию `IXSCAN`.

```python
explain_result = collection.find({"email": "test@example.com"}).explain()
stage = explain_result["executionStats"]["executionStages"]["stage"]
stage
