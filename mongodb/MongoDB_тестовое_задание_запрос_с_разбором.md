# MongoDB: Тестовые задания с решениями

## Задание 1: Базовые запросы

### Условие
Есть коллекция `users` со следующими документами:
```json
{
  "_id": ObjectId("..."),
  "name": "Иван",
  "email": "ivan@example.com",
  "age": 25,
  "status": "active",
  "tags": ["python", "mongodb"],
  "created_at": ISODate("2024-01-15")
}
```

**Задачи:**
1. Найти всех активных пользователей старше 18 лет
2. Найти пользователей с тегами "python" и "mongodb"
3. Обновить статус всех неактивных пользователей на "inactive"
4. Удалить пользователей старше 100 лет

### Решение
См. `mongodb_example.py` - функция `task_1_basic_queries()`
