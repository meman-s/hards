# Практические задания по тестированию

## Как использовать

1. Откройте файл `unit/test_practice.py`
2. Найдите задание по нужной теме
3. Напишите тесты вместо TODO комментариев
4. Запустите тесты: `pytest unit/test_practice.py -v` (из папки testing)

## Структура заданий

### Задание 1: Pytest Fixtures

**Цель:** Научиться создавать и использовать фикстуры

**Задачи:**
1. Создайте фикстуру `bank_account` для `BankAccount` с начальным балансом 100.0
2. Создайте фикстуру `user_repo` с `scope="module"` для `UserRepository`
3. Создайте фикстуру с `autouse=True`, которая выводит "Starting test"

---

### Задание 2: Юнит тесты для BankAccount

**Цель:** Написать изолированные тесты для класса

**Задачи:**
1. Тест `deposit` - проверка увеличения баланса
2. Тест `withdraw` - проверка уменьшения баланса
3. Тест `withdraw` с недостаточным балансом - должен вызывать `ValueError`
4. Тест `transfer` между двумя счетами
5. Тест `transaction_history` - проверка истории операций

---

### Задание 3: Параметризованные тесты

**Цель:** Использовать `@pytest.mark.parametrize` для тестирования с разными данными

**Задачи:**
1. Параметризованный тест для `Calculator.add`
2. Параметризованный тест для `Calculator.multiply`
3. Параметризованный тест для `Calculator.divide`, включая проверку деления на ноль

---

### Задание 4: Юнит тесты для StringProcessor

**Цель:** Тестирование статических методов

**Задачи:**
1. Тест `reverse`, `capitalize_words`, `is_palindrome`, `count_words`
2. Тест для проверки `TypeError` при передаче не-строки

---

### Задание 5: Тесты с моками

**Цель:** Использовать мокирование для изоляции тестов (EmailService, smtp_client)

---

### Задание 6–11

См. полный текст в этом файле в репозитории (интеграционные тесты, ShoppingCart, validate_password, process_numbers, маркеры, E2E).

## Запуск

Из папки `testing/`:
```bash
pytest unit/test_practice.py -v
pytest unit/ -v
pytest -m "not slow" -v
```
