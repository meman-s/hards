# Задания: 11. Тестирование

### Задания
#### Pytest: fixtures, parametrize, markers
Создайте тестовый набор используя:
1. Fixtures для подготовки данных (БД, файлы)
2. Parametrize для тестирования с разными входными данными
3. Markers для категоризации тестов
4. Плагины и кастомные фикстуры
#### Юнит тесты
Напишите unit тесты для:
1. Функций валидации данных
2. Бизнес-логики (расчеты, преобразования)
3. Утилитарных функций
4. Мокирование зависимостей
#### Интеграционные тесты
Создайте интеграционные тесты:
1. Тестирование API эндпоинтов с реальной БД
2. Тестирование взаимодействия сервисов
3. Тестирование работы с внешними API (моки)
4. Тестирование миграций БД
#### E2E тесты: Selenium или Playwright
Создайте E2E тесты используя Playwright:
1. Тест регистрации пользователя
2. Тест процесса покупки товара
3. Тест работы с формами
4. Скриншоты и видео при падении тестов
