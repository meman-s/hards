# Задания: 9. Базы данных

### Задания
#### SQL: Нормализация
Спроектируйте нормализованную схему БД для системы управления проектами (3NF). Определите таблицы, связи и внешние ключи.
#### SQL: Подзапросы
Напишите SQL запросы с использованием:
1. Подзапросов в SELECT
2. Подзапросов в WHERE (IN, EXISTS)
3. Подзапросов в FROM
4. Коррелированных подзапросов
#### SQL: Оконные функции
Используя оконные функции, напишите запросы:
1. Ранжирование сотрудников по зарплате в каждом отделе
2. Вычисление скользящего среднего продаж за 7 дней
3. Сравнение текущей продажи с предыдущей (LAG/LEAD)
4. Подсчет накопительной суммы
#### SQL: Индексы
Создайте индексы для оптимизации запросов:
1. Простой индекс на часто используемое поле
2. Составной индекс для запросов с несколькими условиями
3. Частичный индекс для фильтрации
4. Анализ использования индексов (EXPLAIN)
#### SQL: Триггеры
Создайте триггеры:
1. Автоматическое обновление timestamp при изменении записи
2. Логирование изменений в таблице аудита
3. Валидация данных перед вставкой
4. Каскадное удаление связанных записей
#### SQL: Оптимизация запросов
Оптимизируйте медленный запрос:
1. Используйте EXPLAIN ANALYZE для анализа
2. Добавьте необходимые индексы
3. Перепишите запрос для лучшей производительности
4. Измерьте улучшение
#### SQL: EXPLAIN ANALYZE
Проанализируйте запрос используя EXPLAIN ANALYZE:
1. Определите узкие места
2. Найдите полные сканирования таблиц
3. Проверьте использование индексов
4. Оптимизируйте запрос
#### MongoDB: Запросы
Напишите MongoDB запросы:
1. Поиск документов с несколькими условиями
2. Поиск по массивам и вложенным объектам
3. Обновление документов (updateOne, updateMany)
4. Удаление документов с условиями
#### MongoDB: Агрегации
Создайте pipeline агрегации:
1. Группировка и подсчет
2. Фильтрация и сортировка
3. Вычисление средних значений
4. Объединение данных из нескольких коллекций
#### MongoDB: Join ($lookup)
Используя $lookup, объедините данные:
1. Объединение заказов с информацией о пользователях
2. Множественные $lookup в одном pipeline
3. Условное объединение с $match
#### MongoDB: Индексы
Создайте индексы:
1. Простой индекс на поле
2. Составной индекс для запросов
3. Частичный индекс с условием
4. Текстовый индекс для полнотекстового поиска
5. Анализ использования индексов (explain)
#### Redis: Структуры данных
Реализуйте задачи используя каждую структуру данных:
1. String - счетчики и кеширование
2. Hash - профили пользователей
3. List - очередь задач
4. Set - уникальные теги
5. Sorted Set - рейтинг пользователей
#### Redis: Pub/Sub
Создайте систему уведомлений:
1. Publisher отправляет события
2. Subscriber получает события
3. Множественные подписчики на один канал
4. Паттерн подписки на несколько каналов
