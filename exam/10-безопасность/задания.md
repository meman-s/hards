# Задания: 10. Безопасность

### Задания
#### Защита от инъекций
Реализуйте защиту от:
1. SQL injection - параметризованные запросы
2. NoSQL injection - валидация входных данных
3. Command injection - санитизация команд
4. XPath injection - экранирование специальных символов
#### Безопасное хранение паролей
Реализуйте систему хранения паролей:
1. Хеширование паролей (bcrypt, argon2)
2. Добавление соли (salt)
3. Проверка пароля при входе
4. Защита от brute-force атак
#### HTTPS, TLS/SSL
Настройте HTTPS:
1. Получение SSL сертификата (Let's Encrypt)
2. Настройка Nginx для HTTPS
3. Редирект с HTTP на HTTPS
4. Настройка безопасности заголовков (HSTS, CSP)
