## 1. Алгоритмы: восстановление кратчайшего пути в графе

Дан неориентированный невзвешенный граф в виде списка смежности и две вершины `start` и `target`. Реализуйте функцию `shortest_path_bfs`, которая находит один из кратчайших путей от `start` до `target` с помощью обхода в ширину и возвращает список вершин пути.

Рекомендуется при обходе хранить массив `parent`, где `parent[v]` — вершина, из которой мы первый раз пришли в `v`, чтобы затем восстановить путь в обратном порядке.

**Входные данные:**

- `graph`: список списков, где `graph[i]` содержит номера вершин, смежных с вершиной `i`
- `start`: номер стартовой вершины
- `target`: номер целевой вершины

**Выходные данные:**

- Список вершин от `start` до `target` включительно, если путь существует
- Пустой список, если пути нет

**Пример:**

```python
graph = [[1, 2], [0, 3], [0, 3], [1, 2, 4], [3]]
start = 0
target = 4
```

Один из возможных корректных ответов: `[0, 1, 3, 4]`.

## 2. Алгоритмы: топологическая сортировка задач по зависимостям

Дан ориентированный граф без петель, описывающий зависимости между задачами: из вершины `u` в вершину `v` ведет ребро, если задача `u` должна быть выполнена раньше задачи `v`. Реализуйте функцию `topological_sort_tasks`, которая возвращает один из возможных порядков выполнения задач.

Если граф содержит цикл (то есть корректного порядка нет), функция должна возвращать пустой список.

**Входные данные:**

- `graph`: список списков, где `graph[i]` содержит номера вершин, в которые ведут рёбра из вершины `i`
- `n`: количество вершин

**Выходные данные:**

- Список вершин в порядке топологической сортировки, либо пустой список, если граф содержит цикл

**Пример:**

```python
graph = [[], [0], [0], [1, 2]]
n = 4
```

Возможный результат: `[3, 1, 2, 0]` или любой другой корректный топологический порядок.

## 3. Профилирование и оптимизация кода

Дан следующий код, который находит все повторяющиеся элементы в списке:

```python
def find_duplicates(items):
    duplicates = []
    for i in range(len(items)):
        for j in range(i + 1, len(items)):
            if items[i] == items[j] and items[i] not in duplicates:
                duplicates.append(items[i])
    return duplicates
```

С помощью инструментов профилирования (например, `cProfile`) определите узкое место этого кода и напишите оптимизированную версию функции `find_duplicates_optimized`, работающую за линейное или близкое к линейному время относительно длины списка.

Опишите, какие изменения вы внесли и почему они улучшают производительность.

class UserRepository:

    def add_user(self, user_id, name):

    def get_user(self, user_id):
