## 7. Профилирование и оптимизация кода

Дан следующий код, который объединяет список строк в одну строку:

```python
def join_strings(strings):
    result = ""
    for s in strings:
        result += s
    return result
```

Найдите узкое место в этом коде и оптимизируйте его. Напишите оптимизированную версию функции.

**Анализ сложности:**
- **Неоптимизированное решение:** O(n²) по времени, где n — количество строк. При каждой конкатенации через `+=` создается новая строка, и все предыдущие символы копируются заново. Если строки имеют среднюю длину m, то общая сложность составляет O(m × n²) или O(L × n), где L — общая длина всех строк.
- **Оптимизированное решение:** O(L) по времени, где L — общая длина всех строк. Метод `join()` сначала вычисляет общую длину, затем создает строку нужного размера и копирует все строки один раз, что дает линейную сложность.
