# 11. Тестирование

Материалы для изучения тестирования: pytest, юнит-тесты, интеграционные тесты, E2E тесты.

## 📁 Структура

```
11-тестирование/
├── README.md          # Этот файл
├── вопросы.md         # Вопросы для самопроверки
├── задания.md         # Практические задания
├── теория/            # Теоретические материалы
│   ├── pytest_fixtures_parametrize_markers_теория.md
│   ├── unit_tests_теория.md
│   ├── integration_tests_теория.md
│   ├── e2e_tests_playwright_теория.md
│   ├── моки_vs_реальные_запросы.md
│   ├── PRACTICE_ASSIGNMENTS.md
│   ├── ASSIGNMENTS_TESTS.md
│   └── E2E_PLAYWRIGHT_ASSIGNMENTS.md
└── практика/          # Практические упражнения
    ├── pytest.ini     # Конфигурация pytest
    ├── requirements.txt # Зависимости
    ├── теория/        # Дополнительная теория (если есть)
    ├── примеры/       # Примеры тестов
    │   ├── pytest/    # Pytest и юнит-тесты
    │   ├── unit/      # Юнит-тесты
    │   ├── integration/  # Интеграционные тесты
    │   └── e2e/       # E2E тесты
    ├── код/           # Код для тестирования
    │   ├── practice_code.py
    │   ├── test_tasks.py
    │   └── assignment_functions.py
    └── конфигурация/  # Дополнительные конфигурационные файлы
        └── conftest.py
```

## 📚 Содержание

- Pytest (fixtures, parametrize, markers)
- Юнит-тесты
- Интеграционные тесты
- E2E тесты (Playwright)

## 🚀 Запуск тестов

Из папки `практика/`:

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск всех тестов
pytest

# Запуск тестов из конкретной папки
pytest примеры/pytest/
pytest примеры/unit/
pytest примеры/integration/
pytest примеры/e2e/
```
