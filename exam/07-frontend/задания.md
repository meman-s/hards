# Задания: 7. Frontend

### Задания
#### TypeScript
Создайте типизированный компонент формы регистрации с валидацией. Используйте TypeScript для типов пропсов, состояния и событий.
#### React
Реализуйте компонент TodoList с использованием:
1. Хуков (useState, useEffect, useCallback, useMemo)
2. Кастомных хуков для бизнес-логики
3. Context API для глобального состояния
4. Оптимизации производительности (React.memo, useMemo)
#### Vite или Next.js
Создайте Next.js приложение с:
1. Server-side rendering для страницы блога
2. Static generation для страниц продуктов
3. API routes для CRUD операций
4. Оптимизацией изображений и мета-тегов
