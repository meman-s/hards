# 4. Алгоритмы

Материалы для изучения алгоритмов: обход графов, топологическая сортировка.

## 📁 Структура

```
04-алгоритмы/
├── README.md          # Этот файл
├── вопросы.md         # Вопросы для самопроверки
├── задания.md         # Практические задания
├── теория/            # Теоретические материалы
│   └── README.md      # Теория по алгоритмам на графах
└── практика/          # Практические упражнения
    ├── примеры/       # Примеры реализации алгоритмов
    │   ├── 01_bfs_undirected.py
    │   ├── 02_dfs_undirected.py
    │   ├── 03_bfs_directed.py
    │   ├── 04_dfs_directed.py
    │   ├── 05_topological_sort.py
    │   └── algos.py
    └── упражнения/    # Дополнительные упражнения
        └── [1.py, 2.py, ...]
```

## 📚 Содержание

- Обход неориентированного графа в ширину (BFS)
- Обход неориентированного графа в глубину (DFS)
- Обход ориентированного графа в ширину (BFS)
- Обход ориентированного графа в глубину (DFS)
- Топологическая сортировка
