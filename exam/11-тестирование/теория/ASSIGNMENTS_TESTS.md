# Задания: написать тесты к функциям

Код для тестирования: `assignment_functions.py` (в корне `testing/`).  
Тесты писать в `unit/test_assignment.py` (создать файл самому).

Запуск: из папки `testing/` выполнить `pytest unit/test_assignment.py -v`.

---

## Уровень 1: простые функции

Чистые функции без зависимостей. Достаточно параметризации и проверки результата/исключений.

### 1.1 `parse_int(value: str) -> int`

- Проверить: `"42"` → `42`, `"  -7  "` → `-7`, `"0"` → `0`.
- Проверить исключение для невалидной строки (`"abc"`, `""`).

### 1.2 `is_positive(n: int) -> bool`

- Параметризовать: положительные → `True`, ноль и отрицательные → `False`.

### 1.3 `format_name(first: str, last: str) -> str`

- Проверить формат `"Last, First"` для нескольких пар имён.
- Граничные случаи: пустые строки, только пробелы.

### 1.4 `slugify(text: str) -> str`

- Проверить: пробелы и спецсимволы заменяются на дефис, регистр нижний, лишние дефисы по краям убраны.
- Параметризовать несколько входных строк и ожидаемых slug’ов.

## Уровень 2: функции с граничными случаями и исключениями

Нужны тесты на валидные кейсы, границы и явные проверки исключений.

### 2.1 `safe_divide(a: float, b: float) -> float`

- Успешные случаи: например `(10, 2) → 5.0`, `(-1, 4) → -0.25`.
- Обязательно: при `b == 0` — `ValueError` с текстом про "division by zero".

### 2.2 `parse_date(date_str: str, fmt: str = "%Y-%m-%d") -> Optional[datetime]`

- Валидная строка — возвращается объект `datetime` с ожидаемой датой.
- Невалидная строка или неверный формат — `None`.
- Разные форматы (например `"%d.%m.%Y"`) — отдельный кейс.

### 2.3 `clamp(value: float, low: float, high: float) -> float`

- Значение внутри диапазона — возвращается без изменений.
- Значение меньше `low` — возвращается `low`.
- Значение больше `high` — возвращается `high`.
- При `low > high` — `ValueError` с осмысленным сообщением.

## Уровень 3: моки и классы с состоянием

Проверка взаимодействий и состояния.

### 3.1 `fetch_user(user_id: int, get_http) -> dict`

- Замокать `get_http`. Успешный ответ (например `{"status": 200, "body": {"id": 1, "name": "Test"}}`) — функция возвращает `body`.
- Ответ с ошибкой (например `status != 200`) — `RuntimeError` с текстом из ответа.
- Проверить, что `get_http` вызван с аргументом вида `/users/{user_id}`.

### 3.1.1 `get_current_iso_date() -> str` (патч внешней зависимости)

- Функция вызывает `datetime.now()` из стандартной библиотеки. В тесте нужно **подменить модуль/класс** в том месте, где он импортирован: `@patch('assignment_functions.datetime')`.
- В моке задать `mock_dt.now.return_value = datetime(2025, 6, 15)` (реальный объект даты), вызвать функцию и проверить, что вернулось `"2025-06-15"`.
- Проверить, что `mock_dt.now` вызван ровно один раз. Так же, как в примере с `requests.post` в `test_solutions.py`: патчим по строке пути импорта (`имя_модуля_где_используется.имя_библиотеки`).

### 3.2 Класс `RateLimiter(max_calls, window_seconds)`

- Конструктор: при невалидных аргументах (например `max_calls < 1` или `window_seconds <= 0`) — `ValueError`.
- `allow(now)`: при числе вызовов меньше лимита в одном окне — `True`, при превышении — `False`.
- Явная передача времени `now` в `allow()` и проверка сброса после истечения окна (разные `now`).
- `remaining(now)`: проверка оставшегося числа вызовов до лимита после нескольких `allow()`.

### 3.3 `process_items(items, filter_fn=None, sort_key=None) -> list`

- Без аргументов — возвращает копию списка по смыслу (тот же порядок).
- Только `filter_fn` — отфильтрованный список.
- Только `sort_key` — отсортированный список.
- `filter_fn` и `sort_key` вместе — отфильтровано и отсортировано.
- Пустой список и список из одного элемента — без ошибок.

## Рекомендации

- Импорт: `from assignment_functions import ...`.
- Для параметризации использовать `@pytest.mark.parametrize`.
- Для исключений — `pytest.raises(ValueError, match="...")`.
- Для моков — `unittest.mock.Mock` или `patch`.
- Имена тестов: по смыслу, например `test_parse_int_valid`, `test_safe_divide_by_zero`, `test_rate_limiter_allow_returns_false_when_limit_exceeded`.
