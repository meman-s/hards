# Hards — тяжёлые навыки

Материалы и конспекты по бэкенд-разработке, Python, архитектуре и методологиям. Структура репозитория соответствует разделам из навигации.

## Разделы

| Раздел | Описание |
|--------|----------|
| **Backend** | API, аутентификация, кэширование, FastAPI, Nginx, безопасность, БД и др. |
| **Python** | Коллекции, декораторы, генераторы, типизация, многопоточность и асинхронность |
| **Архитектура** | Стили и подходы, документирование, принципы и паттерны проектирования |
| **Методологии** | Методологии разработки, требования к проекту |
| **Код и алгоритмы** | Примеры: алгоритмы на графах (BFS, DFS, топологическая сортировка) |

## Как собрать документацию

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-docs.txt
mkdocs serve
```

Сайт будет доступен по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000).

Сборка статического сайта для публикации:

```bash
mkdocs build
```

Результат в каталоге `site/`.
