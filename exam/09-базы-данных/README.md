# 9. Базы данных

Материалы для изучения работы с базами данных: SQL, MongoDB, Redis.

## 📁 Структура

```
09-базы-данных/
├── README.md          # Этот файл
├── вопросы.md         # Вопросы для самопроверки
├── задания.md         # Практические задания
├── теория/            # Теоретические материалы
│   ├── sql/
│   │   ├── orm.md     # SQLAlchemy, Alembic
│   │   └── *.sql      # SQL запросы и примеры
│   ├── mongodb/
│   │   ├── README.md
│   │   ├── mongodb_example.py
│   │   └── MongoDB_тестовое_задание_запрос_с_разбором.md
│   └── redis/
│       ├── README.md
│       ├── redis_example.py
│       └── Redis_тестовое_задание_запрос_с_разбором.md
└── практика/          # Практические упражнения (если есть)
```

## 📚 Содержание

### SQL
- Нормализация, подзапросы, оконные функции
- Индексы, триггеры, оптимизация запросов
- ORM (SQLAlchemy, Alembic)

### MongoDB
- Запросы, агрегации, Join ($lookup), индексы

### Redis
- Структуры данных (String, Hash, List, Set, Sorted Set)
- Pub/Sub
