# Задания: 5. Python

### Задания
#### Type hints, mypy, static type checking
Добавьте type hints ко всем функциям в проекте и настройте mypy для проверки типов. Исправьте все ошибки типизации.
#### Dataclasses, attrs, pydantic
Создайте три версии класса User:
1. Используя @dataclass
2. Используя attrs
3. Используя Pydantic
Сравните возможности валидации и производительность.
#### Context managers
Создайте context manager для работы с базой данных, который автоматически открывает и закрывает соединение, а также откатывает транзакцию при ошибке.
#### Decorators
Создайте декораторы для:
1. Логирования вызовов функций
2. Кеширования результатов
3. Измерения времени выполнения
4. Повторных попыток при ошибках
5. Авторизации (проверка прав доступа)
#### Generators, iterators, async generators
Реализуйте:
1. Генератор для чтения большого файла построчно
2. Итератор для обхода дерева каталогов
3. Async генератор для чтения данных из API с пагинацией
#### Collections (deque, Counter, defaultdict, OrderedDict)
Реализуйте задачи используя collections:
1. LRU кеш используя OrderedDict
2. Подсчет частоты слов в тексте используя Counter
3. Очередь задач используя deque
4. Группировка данных по ключам используя defaultdict
#### functools, itertools
Используя functools и itertools:
1. Создайте мемоизированную функцию для вычисления чисел Фибоначчи
2. Реализуйте цепочку обработчиков используя functools.partial
3. Создайте генератор всех комбинаций элементов списка
4. Реализуйте бесконечный генератор последовательностей
#### Threading vs Multiprocessing vs Async
Реализуйте одну и ту же задачу (скачивание 100 файлов) тремя способами:
1. Threading
2. Multiprocessing
3. Async
Сравните производительность и использование ресурсов.
#### Профилирование и оптимизация кода
Профилируйте медленный код и оптимизируйте его:
```python
def process_data(data):
    result = []
    for item in data:
        processed = expensive_operation(item)
        result.append(processed)
    return result
```
Используйте cProfile, line_profiler или memory_profiler.
