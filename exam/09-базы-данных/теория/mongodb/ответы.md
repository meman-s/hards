# MongoDB: Ответы на задания

## Задание 1: Базовые запросы

### 1. Найти всех активных пользователей старше 18 лет
```python
users.find({
    "status": "active",
    "age": {"$gt": 18}
})
```

### 2. Найти пользователей с тегами "python" и "mongodb"
```python
users.find({
    "tags": {"$all": ["python", "mongodb"]}
})
```

### 3. Обновить статус всех неактивных пользователей
```python
users.update_many(
    {"status": {"$ne": "active"}},
    {"$set": {"status": "inactive"}}
)
```

### 4. Удалить пользователей старше 100 лет
```python
users.delete_many({"age": {"$gt": 100}})
```

## Задание 3: $lookup (Join)

### 1. Заказы с информацией о пользователе
```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user"
        }
    },
    {"$unwind": "$user"},
    {
        "$project": {
            "order_id": "$_id",
            "user_name": "$user.name",
            "user_email": "$user.email",
            "total": 1,
            "status": 1
        }
    }
]
result = list(orders.aggregate(pipeline))
```

### 2. Заказы с пользователем и товарами
```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user"
        }
    },
    {"$unwind": "$user"},
    {"$unwind": "$items"},
    {
        "$lookup": {
            "from": "products",
            "localField": "items.product_id",
            "foreignField": "_id",
            "as": "product"
        }
    },
    {"$unwind": "$product"},
    {
        "$group": {
            "_id": "$_id",
            "user_name": {"$first": "$user.name"},
            "total": {"$first": "$total"},
            "items": {"$push": {
                "product_name": "$product.name",
                "quantity": "$items.quantity",
                "price": "$product.price"
            }}
        }
    }
]
result = list(orders.aggregate(pipeline))
```

### 3. Пользователи с количеством заказов и суммой
```python
pipeline = [
    {
```

## Задание 4: Индексы

### 1. Compound индекс для категории, статуса и цены
```python
products.create_index([
    ("category", 1),
    ("status", 1),
    ("price", -1)
])

# Запрос, который использует этот индекс:
products.find({
    "category": "Электроника",
    "status": "active"
}).sort("price", -1)
```

### 2. Partial индекс для активных товаров
```python
products.create_index(
    [("name", 1)],
    partialFilterExpression={"status": "active"}
)
```

### 3. Text индекс для поиска
```python
products.create_index([
    ("name", "text"),
    ("description", "text")
])

# Использование:
products.find({"$text": {"$search": "ноутбук"}})
```

## Задание 5: Комплексное задание

### 1. Топ-5 категорий по выручке
```python
pipeline = [
    {"$match": {"status": "completed"}},
    {"$unwind": "$items"},
    {
        "$lookup": {
            "from": "products",
            "localField": "items.product_id",
            "foreignField": "_id",
            "as": "product"
        }
    },
    {"$unwind": "$product"},
    {
        "$group": {
            "_id": "$product.category",
            "revenue": {"$sum": {"$multiply": ["$items.quantity", "$product.price"]}}
        }
    },
    {"$sort": {"revenue": -1}},
    {"$limit": 5}
]
result = list(orders.aggregate(pipeline))
```

### 2. Средний чек по городам

### 3. Пользователи с заказами > 10000
