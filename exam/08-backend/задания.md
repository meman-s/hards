# Задания: 8. Backend

### Задания
#### RPC vs REST
В чем основные различия между RPC и REST подходами к проектированию API? Когда стоит использовать каждый из них и какие есть альтернативы (например, gRPC, GraphQL)?
#### FastAPI: dependency injection, middleware, background tasks
Создайте FastAPI приложение с:
1. Dependency injection для получения текущего пользователя
2. Middleware для логирования запросов
3. Background tasks для отправки email после регистрации
4. Валидацией данных через Pydantic
#### Pydantic: валидация, сериализация
Создайте модели Pydantic для:
1. Валидации данных пользователя при регистрации
2. Сериализации ответов API
3. Валидации вложенных объектов и списков
4. Кастомных валидаторов
#### SQLAlchemy / Alembic: ORM, миграции
Создайте систему управления библиотекой с:
1. Моделями SQLAlchemy (Book, Author, Reader, Loan)
2. Связями между моделями (one-to-many, many-to-many)
3. Миграциями Alembic для создания и изменения схемы
4. Запросами с использованием ORM (joins, eager loading)
#### ShortPolling, LongPolling, WebSocket, Server-Sent Events
Реализуйте систему уведомлений используя каждый подход:
1. ShortPolling - клиент опрашивает сервер каждые 5 секунд
2. LongPolling - сервер держит соединение открытым до появления события
3. WebSocket - двусторонняя связь для чата
4. SSE - сервер отправляет события клиенту
#### Аутентификация и авторизация
Реализуйте систему аутентификации с:
1. JWT токенами (access и refresh)
2. OAuth2 для входа через Google
3. Session-based auth с cookies
4. Ролевой авторизацией (admin, user, guest)
#### Безопасность
Реализуйте защиту от:
1. CORS - настройка разрешенных источников
2. CSRF - токены для форм
3. XSS - санитизация пользовательского ввода
4. SQL injection - использование параметризованных запросов
5. Rate limiting - ограничение запросов по IP
#### API versioning
Реализуйте версионирование API:
1. URL-based versioning (/api/v1/users, /api/v2/users)
2. Header-based versioning (Accept: application/vnd.api+json;version=2)
3. Миграция с v1 на v2 с обратной совместимостью
#### API documentation: OpenAPI/Swagger
Создайте документацию API используя:
1. Автогенерацию из Pydantic моделей
2. Описание эндпоинтов с примерами
3. Схемы запросов и ответов
4. Интерактивную документацию Swagger UI
#### Nginx: reverse proxy, load balancing
Настройте Nginx для:
1. Reverse proxy для FastAPI приложения
2. Load balancing между 3 инстансами приложения
3. SSL/TLS терминация
4. Статическая раздача файлов
#### Работа с файлами
Реализуйте систему загрузки файлов:
1. Загрузка файлов на сервер
2. Валидация типа и размера
3. Хранение в файловой системе и S3
4. Генерация превью для изображений
5. Скачивание файлов с проверкой прав
#### Кеширование
Реализуйте кеширование:
1. Redis для кеширования результатов запросов к БД
2. In-memory кеш с использованием lru_cache
3. Кеширование с TTL
4. Инвалидация кеша при обновлении данных
