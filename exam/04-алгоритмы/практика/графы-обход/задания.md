# Задания по обходу графов

## Задание 1: Обход неориентированного графа в ширину (BFS)

### Условие
Дан неориентированный граф в виде списка смежности. Реализуйте функцию `bfs_undirected`, которая выполняет обход графа в ширину, начиная с заданной вершины.

**Входные данные:**
- `graph`: список списков, где `graph[i]` содержит номера вершин, смежных с вершиной `i`
- `start`: номер стартовой вершины (0 <= start < n)
- `n`: количество вершин (опционально, по умолчанию `len(graph)`)

**Выходные данные:**
- Список вершин в порядке их посещения при обходе в ширину

**Пример:**
```python
graph = [[1, 2], [0, 3], [0, 4], [1], [2]]
start = 0
# Ожидаемый результат: [0, 1, 2, 3, 4]
```

## Задание 5: Топологическая сортировка

### Условие
Дан ориентированный ациклический граф (DAG) в виде списка смежности. Реализуйте функцию `topological_sort`, которая выполняет топологическую сортировку вершин графа.

**Входные данные:**
- `graph`: список списков, где `graph[i]` содержит номера вершин, в которые ведут рёбра из вершины `i`
- `n`: количество вершин

**Выходные данные:**
- Список вершин в порядке топологической сортировки, или `None`, если граф содержит цикл

**Примечание:** Если граф содержит цикл, верните `None`. Иначе верните любой допустимый порядок вершин.

**Пример:**
```python
graph = [[], [0], [0], [1, 2], [1, 3]]
n = 5
# Ожидаемый результат: [4, 3, 2, 1, 0] (один из возможных вариантов)
```

## Задание 7: Поиск кратчайшего пути (BFS)

### Условие
Дан неориентированный граф в виде списка смежности и две вершины. Реализуйте функцию `shortest_path`, которая находит кратчайший путь между двумя вершинами, используя BFS.

**Входные данные:**
- `graph`: список списков, где `graph[i]` содержит номера вершин, смежных с вершиной `i`
- `start`: начальная вершина
- `end`: конечная вершина
- `n`: количество вершин (опционально, по умолчанию `len(graph)`)

**Выходные данные:**
- Список вершин, образующих кратчайший путь от `start` до `end`, или `None`, если путь не существует

**Пример:**
```python
graph = [[1, 2], [0, 3], [0, 4], [1], [2]]
start = 0
end = 4
# Ожидаемый результат: [0, 2, 4]
```

## Задание 8: Проверка наличия цикла в ориентированном графе

### Условие
Дан ориентированный граф в виде списка смежности. Реализуйте функцию `has_cycle`, которая проверяет, содержит ли граф цикл.

**Входные данные:**
- `graph`: список списков, где `graph[i]` содержит номера вершин, в которые ведут рёбра из вершины `i`
- `n`: количество вершин (опционально, по умолчанию `len(graph)`)

**Выходные данные:**
- `True`, если граф содержит цикл, иначе `False`

**Пример:**
```python
graph = [[1], [2], [0]]
n = 3
# Ожидаемый результат: True (есть цикл 0 -> 1 -> 2 -> 0)

graph = [[1], [2], []]
n = 3
# Ожидаемый результат: False (цикла нет)
```
