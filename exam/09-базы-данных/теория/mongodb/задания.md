# MongoDB: Практические задания

## Задание 1: Базовые запросы

### Условие
Коллекция `users`:
```json
{
  "_id": ObjectId("..."),
  "name": "Иван",
  "email": "ivan@example.com",
  "age": 25,
  "status": "active",
  "tags": ["python", "mongodb"],
  "created_at": ISODate("2024-01-15")
}
```

**Задачи:**
1. Найти всех активных пользователей старше 18 лет
2. Найти пользователей с тегами "python" и "mongodb" одновременно
3. Обновить статус всех неактивных пользователей на "inactive"
4. Удалить пользователей старше 100 лет

---

## Задание 2: Агрегации

### Условие
Коллекция `orders`:
```json
{
  "_id": ObjectId("..."),
  "user_id": ObjectId("..."),
  "items": [
    {"product_id": ObjectId("..."), "quantity": 2, "price": 100},
    {"product_id": ObjectId("..."), "quantity": 1, "price": 50}
  ],
  "status": "completed",
  "created_at": ISODate("2024-01-15"),
  "total": 250
}
```

**Задачи:**
1. Найти общую сумму всех завершенных заказов
2. Найти средний чек по статусам заказов
3. Найти топ-5 пользователей по сумме заказов
4. Найти количество заказов по месяцам

---

## Задание 3: $lookup (Join)

### Условие
Три коллекции:
- `orders` - заказы с полями: user_id, items[], total, status
- `users` - пользователи с полями: name, email
- `products` - товары с полями: name, price

**Задачи:**
1. Найти все заказы с информацией о пользователе (имя, email)
2. Найти заказы с информацией о пользователе и товарах в каждом заказе
3. Найти пользователей с количеством их заказов и общей суммой потраченных средств
4. Найти товары с количеством раз, когда они были заказаны

---

## Задание 4: Индексы

### Условие
Коллекция `products`:
- `name` - название товара
- `category` - категория
- `price` - цена
- `status` - статус (active, inactive)
- `created_at` - дата создания
- `description` - описание

**Задачи:**
1. Создать compound индекс для запроса: найти активные товары в категории "Электроника", отсортированные по цене по убыванию
2. Создать partial индекс для активных товаров на поле `name`
3. Создать text индекс для поиска по `name` и `description`
4. Проверить использование индексов через `explain()`

---

## Задание 5: Комплексное задание

### Условие
Есть коллекции:
- `users` - пользователи (name, email, city)
- `orders` - заказы (user_id, items[], status, total, created_at)
- `products` - товары (name, category, price)

**Задачи:**
1. Найти топ-5 категорий товаров по выручке (используя $lookup для получения цены товара)
2. Найти средний чек по городам пользователей
3. Найти пользователей, которые сделали заказы на сумму больше 10000
4. Создать compound индекс для оптимизации запроса: найти заказы пользователя со статусом "completed", отсортированные по дате
