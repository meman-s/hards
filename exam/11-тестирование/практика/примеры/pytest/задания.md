## Задание 1: Юнит-тесты для класса Calculator

### Описание
Дан класс `Calculator` с методами для выполнения математических операций. Класс ведет историю всех операций.

### Исходный код
```python
class Calculator:
    def __init__(self):
        self.history = []
    
    def add(self, a, b):
        result = a + b
        self.history.append(f"{a} + {b} = {result}")
        return result
    
    def subtract(self, a, b):
        result = a - b
        self.history.append(f"{a} - {b} = {result}")
        return result
    
    def multiply(self, a, b):
        result = a * b
        self.history.append(f"{a} * {b} = {result}")
        return result
    
    def divide(self, a, b):
        if b == 0:
            raise ValueError("Деление на ноль невозможно")
        result = a / b
        self.history.append(f"{a} / {b} = {result}")
        return result
    
    def power(self, base, exponent):
        result = base ** exponent
        self.history.append(f"{base} ^ {exponent} = {result}")
        return result
    
    def get_history(self):
        return self.history
    
    def clear_history(self):
        self.history = []
```

### Задача
Напишите юнит-тесты для всех методов класса `Calculator`:
- `test_add` - тест сложения (включая отрицательные числа и ноль)
- `test_subtract` - тест вычитания
- `test_multiply` - тест умножения
- `test_divide` - тест деления (включая деление на ноль с проверкой исключения)
- `test_power` - тест возведения в степень
- `test_history` - тест работы с историей операций
- `test_clear_history` - тест очистки истории

## Задание 2: Параметризованные тесты с @pytest.mark.parametrize

### Описание
Дан класс `UserValidator` с методами валидации email и пароля. Нужно написать параметризованные тесты для проверки множества случаев.

### Исходный код
```python
class UserValidator:
    @staticmethod
    def validate_email(email):
        if not email or "@" not in email:
            return False
        parts = email.split("@")
        if len(parts) != 2:
            return False
        local, domain = parts
        if not local or not domain:
            return False
        if "." not in domain:
            return False
        return True
    
    @staticmethod
    def validate_password(password):
        if len(password) < 8:
            return False, "Пароль должен содержать минимум 8 символов"
        if not any(c.isupper() for c in password):
            return False, "Пароль должен содержать хотя бы одну заглавную букву"
        if not any(c.islower() for c in password):
            return False, "Пароль должен содержать хотя бы одну строчную букву"
        if not any(c.isdigit() for c in password):
            return False, "Пароль должен содержать хотя бы одну цифру"
        return True, "Пароль валиден"
```

### Задача
Напишите параметризованные тесты, используя `@pytest.mark.parametrize`:
- `test_valid_emails` - тесты для валидных email адресов (минимум 5 различных случаев)
- `test_invalid_emails` - тесты для невалидных email адресов (минимум 5 различных случаев)
- `test_validate_password` - параметризованный тест для валидации пароля с проверкой различных сценариев

## Задание 3: Тесты с использованием fixtures

### Описание
Дан класс `DatabaseConnection` для работы с базой данных. Нужно написать тесты, используя fixtures для подготовки тестового окружения.

### Исходный код
```python
class DatabaseConnection:
    def __init__(self, connection_string):
        self.connection_string = connection_string
        self.connected = False
        self.data = {}
    
    def connect(self):
        if not self.connection_string:
            raise ValueError("Connection string не может быть пустым")
        self.connected = True
        return True
    
    def disconnect(self):
        self.connected = False
    
    def insert(self, table, record):
        if not self.connected:
            raise RuntimeError("Нет подключения к базе данных")
        if table not in self.data:
            self.data[table] = []
        self.data[table].append(record)
        return len(self.data[table]) - 1
    
    def select(self, table, condition=None):
        if not self.connected:
            raise RuntimeError("Нет подключения к базе данных")
        if table not in self.data:
            return []
        if condition is None:
            return self.data[table]
        return [r for r in self.data[table] if condition(r)]
    
    def delete(self, table, condition):
        if not self.connected:
            raise RuntimeError("Нет подключения к базе данных")
        if table not in self.data:
            return 0
        initial_count = len(self.data[table])
        self.data[table] = [r for r in self.data[table] if not condition(r)]
        return initial_count - len(self.data[table])
```

### Задача
Напишите тесты с использованием fixtures:
- Создайте fixture `db_connection` для подключения к базе данных (используйте `scope="function"`)
- Создайте fixture `sample_data` для тестовых данных
- Напишите тесты для методов `connect`, `insert`, `select`, `delete`
- Проверьте обработку ошибок (пустой connection string, операции без подключения)

## Задание 4: Тесты с использованием markers

### Описание
Дан класс `CacheService` для работы с кэшем. Нужно написать тесты и разделить их на категории с помощью маркеров.

### Исходный код
```python
class CacheService:
    def __init__(self, max_size=100):
        self.cache = {}
        self.max_size = max_size
        self.hits = 0
        self.misses = 0
    
    def get(self, key):
        if key in self.cache:
            self.hits += 1
            return self.cache[key]
        self.misses += 1
        return None
    
    def set(self, key, value):
        if len(self.cache) >= self.max_size and key not in self.cache:
            oldest_key = next(iter(self.cache))
            del self.cache[oldest_key]
        self.cache[key] = value
    
    def clear(self):
        self.cache.clear()
        self.hits = 0
        self.misses = 0
    
    def get_stats(self):
        total = self.hits + self.misses
        if total == 0:
            return {"hits": 0, "misses": 0, "hit_rate": 0.0}
        return {
            "hits": self.hits,
            "misses": self.misses,
            "hit_rate": self.hits / total
        }
```

### Задача
Напишите тесты и разделите их на категории:
- `test_fast_operations` - пометьте маркером `@pytest.mark.fast` (тесты для get, set, clear, stats)
- `test_slow_operations` - пометьте маркером `@pytest.mark.slow` (тест для max_size)
- `test_integration` - пометьте маркером `@pytest.mark.integration` (комплексный тест workflow)

**Дополнительно:** Создайте файл `conftest.py` или `pytest.ini` для регистрации маркеров.

## Задание 5: Комбинированное задание - fixtures + parametrize

### Описание
Дана функция `fibonacci` для вычисления чисел Фибоначчи. Нужно написать тесты, используя и fixtures, и parametrize.

### Исходный код
```python
def fibonacci(n):
    if n < 0:
        raise ValueError("n должно быть неотрицательным")
    if n == 0:
        return 0
    if n == 1:
        return 1
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b
```

### Задача
Напишите тесты, комбинируя fixtures и parametrize:
- Используйте fixture для подготовки ожидаемых результатов
- Используйте `@pytest.mark.parametrize` для проверки различных значений n (0, 1, 2, 3, 5, 10, 20)
- Проверьте граничные случаи (n=0, n=1)
- Проверьте обработку ошибок (отрицательные значения)
- Напишите отдельный тест, который использует fixture с ожидаемыми результатами

## Задание 6: Тесты с временными файлами (fixtures с yield)

### Описание
Дан класс `FileProcessor` для работы с файлами. Нужно написать тесты, используя fixtures, которые создают временные файлы.

### Исходный код
```python
class FileProcessor:
    def __init__(self, encoding="utf-8"):
        self.encoding = encoding
    
    def read_file(self, filepath):
        with open(filepath, "r", encoding=self.encoding) as f:
            return f.read()
    
    def write_file(self, filepath, content):
        with open(filepath, "w", encoding=self.encoding) as f:
            f.write(content)
    
    def process_file(self, input_path, output_path):
        content = self.read_file(input_path)
        processed = content.upper().replace(" ", "_")
        self.write_file(output_path, processed)
        return processed
```

### Задача
Напишите тесты с использованием fixtures, которые создают временные файлы:
- Создайте fixture `temp_file` для входного файла с тестовыми данными
- Создайте fixture `temp_output_file` для выходного файла
- Используйте `yield` для очистки файлов после теста
- Напишите тесты для методов `read_file`, `write_file`, `process_file`
- Убедитесь, что временные файлы удаляются после каждого теста
