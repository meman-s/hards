Материалы для изучения проектирования программного обеспечения: архитектурные стили, паттерны проектирования, принципы.


- Архитектурные стили (луковая, микросервисная, событийно-ориентированная)
- Паттерны проектирования GoF
- Архитектурные паттерны (Repository, Unit of Work, CQRS)
- Принципы: SOLID, DRY, KISS, YAGNI
