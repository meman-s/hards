# Hards — тяжёлые навыки

Конспекты и материалы по бэкенду, Python, архитектуре и методологиям.

Документация собрана с помощью [MkDocs](https://www.mkdocs.org/) и темы [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).

## Запуск документации локально

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-docs.txt
mkdocs serve
```

Откройте в браузере: [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Сборка статического сайта

```bash
mkdocs build
```

Результат в каталоге `site/`.

## Структура репозитория

- **exam/** — все материалы для подготовки к экзамену (структурированные по темам с нумерацией)
  - Каждая тема содержит: `теория/`, `практика/`, `вопросы.md`, `задания.md`
  - Все материалы находятся внутри `exam/` - не нужно искать в других местах!

Конфигурация навигации: `mkdocs.yml`.

## 📚 Подготовка к экзамену

Для подготовки к экзамену используйте материалы в папке **exam/**:
- Все темы структурированы и пронумерованы (01-12)
- Каждая тема содержит:
  - `теория/` — вся теория по теме
  - `практика/` — практические упражнения
  - `вопросы.md` и `задания.md` — для самопроверки
- **Все материалы в одном месте** — не нужно искать в корне проекта
- См. [exam/README.md](./exam/README.md) для подробной навигации

**Как использовать:**
1. Откройте нужную тему: `exam/05-python/`
2. Всё уже внутри: теория в `теория/`, практика в `практика/`
3. Изучайте материалы, отвечайте на вопросы, выполняйте задания
