# Hards — тяжёлые навыки

Конспекты и материалы по бэкенду, Python, архитектуре и методологиям.

Документация собрана с помощью [MkDocs](https://www.mkdocs.org/) и темы [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).

## Запуск документации локально

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-docs.txt
mkdocs serve
```

Откройте в браузере: [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Сборка статического сайта

```bash
mkdocs build
```

Результат в каталоге `site/`.

## Структура репозитория

- **backend/** — API, аутентификация, кэширование, FastAPI, безопасность, БД и др.
- **python/** — коллекции, декораторы, генераторы, типизация, многопоточность
- **архитектура/** — архитектурные стили, документирование, принципы и паттерны
- **методологии/** — методологии разработки, требования к проекту
- **code/** — примеры кода (алгоритмы на графах и др.)

Конфигурация навигации: `mkdocs.yml`.
