# 8. Backend

Материалы для изучения backend разработки: API, FastAPI, базы данных, безопасность.

## 📁 Структура

```
08-backend/
├── README.md          # Этот файл
├── вопросы.md         # Вопросы для самопроверки
├── задания.md         # Практические задания
├── теория/            # Теоретические материалы
│   ├── api/           # RPC vs REST, API versioning, документация
│   ├── fastapi/       # FastAPI, Pydantic
│   ├── database/      # SQLAlchemy, Alembic
│   ├── auth/          # Аутентификация и авторизация
│   ├── security/      # Безопасность
│   ├── communication/ # ShortPolling, LongPolling, WebSocket, SSE
│   ├── files/         # Работа с файлами
│   ├── caching/       # Кеширование
│   └── nginx/         # Nginx
└── практика/          # Практические упражнения
    └── fullstack-project/  # Полноценный проект
```

## 📚 Содержание

- RPC vs REST, FastAPI, Pydantic
- SQLAlchemy / Alembic (ORM, миграции)
- Аутентификация и авторизация (JWT, OAuth2)
- Безопасность (CORS, CSRF, XSS, SQL injection)
- API versioning, документация
- Nginx (reverse proxy, load balancing)
- Работа с файлами, кеширование
