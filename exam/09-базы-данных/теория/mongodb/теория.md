# MongoDB: Теория для экзамена

## 1. Запросы

### Базовые операции

```python
# Найти все документы
collection.find({})

# Найти с условием
collection.find({"status": "active"})

# Найти один документ
collection.find_one({"name": "Иван"})

# Сортировка и лимит
collection.find({}).sort("created_at", -1).limit(10)
```

### Операторы сравнения
- `$gt` - больше
- `$gte` - больше или равно
- `$lt` - меньше
- `$lte` - меньше или равно
- `$ne` - не равно
- `$in` - входит в массив
- `$nin` - не входит в массив

```python
collection.find({"age": {"$gte": 18, "$lte": 65}})
collection.find({"status": {"$in": ["active", "pending"]}})
```

### Логические операторы
- `$and` - логическое И
- `$or` - логическое ИЛИ
- `$not` - логическое НЕ

```python
collection.find({
    "$and": [
        {"age": {"$gte": 18}},
        {"status": "active"}
    ]
})
```

### Операторы для массивов
- `$all` - все элементы присутствуют
- `$elemMatch` - хотя бы один элемент соответствует условию
- `$size` - размер массива

```python
collection.find({"tags": {"$all": ["python", "mongodb"]}})
collection.find({"scores": {"$elemMatch": {"$gte": 80}}})
```

### Update операции
```python
# Обновить один документ
collection.update_one(
    {"_id": ObjectId("...")},
    {"$set": {"status": "active"}}
)

# Обновить несколько
collection.update_many(
    {"status": "pending"},
    {"$set": {"status": "active"}}
)

# Операторы: $set, $unset, $inc, $push, $pull
```

### Delete операции
```python
collection.delete_one({"_id": ObjectId("...")})
collection.delete_many({"status": "deleted"})
```

## 2. Агрегации

Агрегация - pipeline из стадий, которые обрабатывают документы последовательно.

### Основные стадии

#### $match - фильтрация
```python
pipeline = [
    {"$match": {"status": "active", "age": {"$gte": 18}}}
]
```

#### $group - группировка
```python
pipeline = [
    {
        "$group": {
            "_id": "$category",
            "total": {"$sum": "$price"},
            "count": {"$sum": 1},
            "avg_price": {"$avg": "$price"},
            "max_price": {"$max": "$price"},
            "min_price": {"$min": "$price"}
        }
    }
]
```

#### $project - выбор полей
```python
pipeline = [
    {
        "$project": {
            "name": 1,
            "age": 1,
            "_id": 0
        }
    }
]
```

#### $sort - сортировка
```python
pipeline = [
    {"$sort": {"created_at": -1}}
]
```

#### $limit и $skip - пагинация
```python
pipeline = [
    {"$skip": 10},
    {"$limit": 20}
]
```

#### $unwind - развертывание массива
```python
pipeline = [
    {"$unwind": "$items"}
]
```

#### $lookup - объединение коллекций
```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user_info"
        }
    }
]
```

### Пример: Статистика по категориям
```python
pipeline = [
    {"$match": {"status": "active"}},
    {
        "$group": {
            "_id": "$category",
            "total_revenue": {"$sum": "$price"},
            "order_count": {"$sum": 1},
            "avg_price": {"$avg": "$price"}
        }
    },
    {"$sort": {"total_revenue": -1}},
    {"$limit": 10}
]
result = list(collection.aggregate(pipeline))
```

## 3. Join ($lookup)

`$lookup` выполняет операции, аналогичные JOIN в реляционных БД.

### Базовый $lookup
```python
pipeline = [
    {
        "$lookup": {
            "from": "users",              # коллекция для объединения
            "localField": "user_id",       # поле в текущей коллекции
            "foreignField": "_id",         # поле в объединяемой коллекции
            "as": "user"                  # имя поля для результата
        }
    }
]
```

### $lookup с $unwind
```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user"
        }
    },
    {
        "$unwind": {
            "path": "$user",
            "preserveNullAndEmptyArrays": True
        }
    }
]
```

### Множественный $lookup
```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user"
        }
    },
    {"$unwind": "$user"},
    {
        "$lookup": {
            "from": "products",
            "localField": "product_id",
            "foreignField": "_id",
            "as": "product"
        }
    },
    {"$unwind": "$product"}
]
```

### Пример: Заказы с пользователем и товарами
```python
pipeline = [
    {
        "$lookup": {
            "from": "users",
            "localField": "user_id",
            "foreignField": "_id",
            "as": "user"
        }
    },
    {"$unwind": "$user"},
    {"$unwind": "$items"},
    {
        "$lookup": {
            "from": "products",
            "localField": "items.product_id",
            "foreignField": "_id",
            "as": "product"
        }
    },
    {"$unwind": "$product"},
    {
        "$group": {
            "_id": "$_id",
            "user_name": {"$first": "$user.name"},
            "total": {"$first": "$total"},
            "items": {"$push": {
                "product_name": "$product.name",
                "quantity": "$items.quantity"
            }}
        }
    }
]
```

## 4. Индексы

Индексы ускоряют выполнение запросов.

### Одиночный индекс
```python
collection.create_index("email")
collection.create_index([("created_at", -1)])  # -1 = по убыванию
```

### Compound индекс (составной)
Индекс на несколько полей. Порядок полей важен!

```python
# Индекс эффективен для запросов:
# - user_id
# - user_id + created_at
# НО НЕ для запросов только по created_at
collection.create_index([("user_id", 1), ("created_at", -1)])
```

**Правило ESR** (Equality, Sort, Range):
1. **E**quality - поля с точным совпадением
2. **S**ort - поля для сортировки
3. **R**ange - поля с операторами сравнения

```python
# Запрос: status="active", сортировка по дате, фильтр price >= 100
collection.create_index([("status", 1), ("created_at", -1), ("price", 1)])
```

### Partial индекс
Индекс только для документов, соответствующих условию.

```python
# Индекс только для активных пользователей
collection.create_index(
    [("email", 1)],
    partialFilterExpression={"status": "active"}
)

# Индекс для документов с score >= 0
collection.create_index(
    [("score", 1)],
    partialFilterExpression={"score": {"$gte": 0}}
)
```

### Text индекс
Для полнотекстового поиска.

```python
# Text индекс на несколько полей
collection.create_index([
    ("title", "text"),
    ("description", "text")
])

# Использование
collection.find({"$text": {"$search": "mongodb python"}})
```

### Управление индексами
```python
# Просмотр индексов
indexes = list(collection.list_indexes())
for index in indexes:
    print(index)

# Удаление индекса
collection.drop_index("email_1")
```

### Анализ использования индексов
```python
explain_result = collection.find({"email": "test@example.com"}).explain()
if explain_result["executionStats"]["executionStages"]["stage"] == "IXSCAN":
    print("Индекс используется!")
```
