Материалы для изучения работы с требованиями к программному обеспечению.

## 📁 Структура

```
02-сбор-и-анализ-требований/
├── README.md          # Этот файл
├── вопросы.md         # Вопросы для самопроверки
├── задания.md         # Практические задания
```

- CRUD-анализ, MoSCoW, INVEST
- Пользовательские истории, use cases
- Критерии приемки (Given-When-Then)
- Трассировка требований
- Документы (SRS, Product Vision, Устав проекта)
