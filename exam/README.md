## 🚀 Как начать изучение

### Для новичков

1. **Начните с первой темы** - [01. Методологии разработки](./01-методологии-разработки/)
2. **Изучайте последовательно** - каждая тема строится на предыдущих
3. **Практикуйтесь** - выполняйте задания после изучения теории
4. **Проверяйте решения** - сравнивайте свои ответы с примерами

### Для повторения

1. **Используйте вопросы** - в каждой теме есть файл `вопросы.md` для самопроверки
2. **Решайте задания** - файл `задания.md` содержит практические задачи
3. **Изучайте примеры** - папка `решения/` содержит примеры правильных решений

## 📁 Структура каждой темы

Каждая тема содержит:

```
XX-название-темы/
├── README.md          # Описание темы и структуры
├── вопросы.md         # Вопросы для самопроверки
├── задания.md         # Практические задания
├── теория/            # Вся теория по теме (скопирована из корня)
│   └── ...
└── практика/          # Практические упражнения
    └── ...
```

**Важно:** Все материалы теперь находятся внутри `exam/`. Теория и практика скопированы в соответствующие темы, так что вам не нужно переходить по ссылкам - все уже здесь!

## 📦 Организация материалов

**Все материалы находятся внутри `exam/`!**

- **Теория** скопирована в папку `теория/` каждой темы
