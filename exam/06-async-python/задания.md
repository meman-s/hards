# Задания: 6. Async Python

### Задания
#### asyncio: event loop, tasks, coroutines
Создайте асинхронное приложение, которое:
1. Запускает 3 корутины параллельно
2. Создает задачи из корутин
3. Ожидает завершения всех задач
4. Обрабатывает результаты и ошибки
#### async/await syntax
Реализуйте асинхронный клиент для работы с API:
1. Асинхронная функция для GET запроса
2. Параллельные запросы к нескольким эндпоинтам
3. Обработка ошибок и таймаутов
4. Использование asyncio.gather и asyncio.create_task
