# Frontend

Одна страница: список элементов с API, форма добавления.

- В разработке: открой `index.html` в браузере и укажи в коде или через прокси API на `http://localhost:8000/api`, либо раздавай фронт с того же origin, что и бэкенд (CORS уже открыт).
- В проде: Nginx раздаёт статику из этой папки и проксирует `/api` на backend.
